# 单晶方法与脚本联动

## 输入到结果
先盘点样品与版本：原始帧、未合并观测、可靠 HKL、只有 CIF/RES 是不同输入层级。配套强度可进入解结构和精修；只有模型可做文件、几何与化学诊断，无法凭空重算 R。Bruker 遮罩或背景校准帧不等于实验衍射帧。

1. 用 scripts/inventory_crystal_input.py 保存输入类型、目录或 ZIP 内容与证据。与 scripts/01_diagnose.py 的模型诊断互补。
2. 配体身份不清时用 scripts/prepare_ligand.py 核对连接、立体化学和原子映射；有机主技能处理化学矛盾。RDKit 参考坐标不替代实测坐标。
3. 有 INS/RES/HKL 先原样复现，再按差密度、ADP、特殊位置、占有率、无序或孪晶问题做单项对照。脚本参数先读 --help；脚本不会替代当前证据决定 PART/FVAR、空间群或删反射。
4. 原始帧或积分证据要求重还原才用 DIALS；保留索引和几何、反射集合、误差模型与尺度信息。不同集合的 R1(gt)不能直接排序。
5. 当前唯一模型产生匹配 CIF/FCF，再做完整验证和交付检查。把原始文件、工作副本、最终文件和验证回执分开；统计、元数据和结论都绑定当前版本。

## 孪晶与格式问题
先按倒易点阵重叠和实际观测协议区分孪晶类型。合并的 HKL 无法恢复已丢失的非重叠组分；HKLF 5 需要观测和分量归属证据。PLATON TwinRotMat 的 FCF 兼容问题与孪晶模型成立是两件事：保留原 FCF，只在诊断副本上调查标签、权重、反射列与程序版本，绝不编造缺少的字段。原辅助脚本及来源获取方法见 modules/solve-single-crystal/WORKFLOW.md。

## 与另外五个主技能交接
把样品和当前模型 ID、原子对应、组成、支持及冲突证据交有机/解谱；由学术研究核实方法先例，由写作入口将核实后的结构与统计组织成汇报。生成 ZIP 或清除警报不代表科学模型已确证。
