# Codex 与 DeepSeek Harness

本技能使用通用 SKILL.md、Markdown参考、相对资源和命令行脚本。Codex与DSH使用同一份方法；不要求目标用户拥有Codex桌面、某一插件名称或来源电脑的盘符。

| 环节 | Codex | DSH |
|---|---|---|
| 加载方法 | 读取SKILL.md及按需参考 | 使用skill工具或读取同一文件 |
| 本地计算与处理 | 当前可用的命令执行工具和Python | 当前可用的命令执行工具和Python |
| 文献检索 | 已连接的学术MCP或网页检索 | 已连接的学术MCP、modsearch或宿主网页检索 |
| Word PPT Excel PDF | 当前文档、演示、表格、PDF能力 | 当前office及office-docx/pptx/xlsx等能力 |
| 图形或浏览器 | 任务确需且已有权限时使用宿主工具 | 同样按任务需要与宿主工具选择 |

模块内的某个API名是能力示例。先确认宿主实际工具能做什么，再完成同等任务；没有对应能力时说明当前可做范围，不能假称已查询、执行或验收。返回格式可以适配宿主，科学参数、证据边界和结果核对规则保持一致。

在技能目录之外执行脚本时，使用实际绝对脚本路径；不要把当前工作目录误当技能目录。普通Python、DIALS和逆合成环境分别选择。工具脚本的--help说明真实参数，先验证必需依赖和输入，不整批安装所有模块的依赖。

如果本机存在统一science.ps1，可继续使用其有效配置；其他电脑可以直接用已配置Python和SHELX、Gaussian、ORCA、xTB等程序。CODEX_HOME、DSH_HOME及作者的程序目录不是科学方法所需的固定路径。外部软件、模型、账号、付费库和许可证均不随技能安装提供。

用户只要求知识或方案时不检查整台电脑，也不启动计算。主流程按当前问题规模执行，不因迁移到另一宿主而要求更多确认、完整综述或额外软件。
