# 融合后的单晶方法

以本技能当前输入分级、基线复现和单变量对照为主。solve-single-crystal 的输入盘点、配体参考、空间群与孪晶思路已经在本技能实现；模块留作完整来源参考，不重开第二条精修流水线。

“处理 A 级警报”先定位当前 CIF/FCF 对应模型与警报对象；警报是待调查线索，不能用删反射或编实验字段消警报。“这个无序分组不对”先看组分连接、互斥、占有率及特殊位置，再修改 PART/FVAR。“对比还原前后”同时报告反射集合和误差模型，避免直接比较不同强度集合的 R。

已有可靠 HKL 从 SHELXL/Olex2 进入；原始帧或积分有异常才进入 DIALS。正式交付选择当前唯一模型，绑定匹配的强度、CIF/FCF、命令日志和哈希，分开源数据、过程与交付目录。在线验证沿用当前样品和目的地的有效授权。

来源模块里“所有群都要试、必须退孪晶、A=0 才完成”等固定要求不提升为本技能规则；按当前衍射与化学证据决定必要对照。原有科学不变量和所有脚本保留。
