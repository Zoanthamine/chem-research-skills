# 围绕化学科研的写作支持

| 目标 | 默认完整模块 |
|---|---|
| 论文论证、摘要引言讨论 | nature-writing |
| 已有文字润色和翻译 | nature-polishing |
| 学位论文和章节 | paper-write |
| 开题与研究计划 | nature-proposal-writer |
| 真实审稿回复 | nature-response |
| 日报、组会、答辩、可编辑 Word/PPT | office-academic-skill |
| 共同引用/样式资源 | nature-shared |

输入来自四核心的当前模型、归属表、计算结果和机理证据，以及研究入口的原文位置。先围绕问题、证据和限制组织表达，再选择当前需要的一种成品。局部润色只处理当前范围；缺少实验或文献支持的部分保持缺项。

实际 Word/PPT/PDF 生成优先用宿主已有能力或 office 模块中适用的工具；保留原文件并渲染检查。需要新的统计、数据分析或化学判断时回对应核心，避免为一份汇报加载全部分析框架。特殊方法和原始完整脚本见 optional-methods.md，按需恢复。
