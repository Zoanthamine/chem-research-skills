# 从证据到论文和科研成品的联动

| 当前目标 | 首选完整模块 | 补充条件 |
|---|---|---|
| 新论文论证、正文 | nature-writing | scientific-writing 做特定一致性/报告检查 |
| 已有文字润色、翻译 | nature-polishing | 保留原含义、数据和结论强度 |
| 学位论文和章节 | paper-write | 按学校现行要求选择完整 reference 分支 |
| 开题、研究计划、项目申请 | nature-proposal-writer / research-grants | 依据目标文档选择一个主实现 |
| 真实审稿回复 | nature-response | 一条意见对应实际改动、证据与稿件位置 |
| 明确要求模拟评审 | nature-reviewer / peer-review | 模拟评审和作者回复分开 |
| Word 阅读报告、组会/答辩 PPT | office-academic-skill | 复用其完整模板处理、文本检查、缩略图与溢出工具；宿主已有文档能力优先 |
| 图表与统计 | nature-data / nature-statistics / nature-figure | 按数据和目标再选具体统计或绘图库 |

## 保留研究故事和可编辑证据
先从已有分析表、谱图归属、当前单晶模型、计算结果和文献证据中提取中心问题、竞争解释和限制。主张与对应数据/原文位置相连；计划、推断、已完成结果分开。已有局部润色无需重建论文档案；需要完整汇报时再展开研究主线。

## 从内容到成品
完整 office-academic-skill 保留 OOXML、模板匹配、现有 PPT 文本与对象盘点、可编辑修改、备注、缩略图、渲染和溢出检查资料及脚本。先确认实际输入和输出路径，保留原文档；运行脚本前读 --help 并检查依赖。Office COM/PowerShell 分支属于 Windows 可选能力，Linux/macOS 使用可用的文档生成与渲染实现；不强制安装商业 Office。

图表选独立实验单位、合适统计模型、误差/区间和对照。绘图和版式审核不能证明科学结论正确。nature-figure 中未捆绑的上游示例图/原始数据保留获取入口与方法说明，不是唯一可执行绘图方案。所有方法、参考和脚本见 CAPABILITIES.md。
