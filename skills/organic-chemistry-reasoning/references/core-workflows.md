# 有机分析的主要方法与四核心联动

## 从真实结构建立竞争解释
先确定当前问题属于组成、连接、相对构型、绝对构型、反应转化还是机理。建立原子/官能团图，检查价态、电荷、保护基、可迁移基团、相邻 π 系统、内外位点和进攻面的构象依据。结构工具提供身份、几何和守恒信息，实验与文献分别决定能支持的结论。

## 反应与谱图一起看
把“原料没了、目标峰没有、多了两个氢、脱 OAc、脱丙酮叉、新 CH2、缺碳”等观察放回具体候选：比较分子式变化、加合离子、碎片/源内反应、原料残留和后处理分解。相同 m/z 不能区分重排异构体；中性丢失不能直接当作已分离副产物。核磁的碳类型、氢数、长程与空间相关用于排除连接，保留杂峰、重叠和阴性证据的检测边界。

## 机理、选择性与实验复盘
比较离子/自由基、取代/消除/重排等竞争路径时，核对真实底物、试剂状态、酸碱、水氧、溶剂、温度和加料顺序。保护/脱保护、内外醛、Wittig 或硫化选择性依实际结构和先例，不能把一个命名反应套到所有底物。图式中的原子、氢、电荷和电子箭头须守恒，漂亮图和模板反应不是机理确证。

把反应、取样、淬灭、萃取、吸附、分离和检测分开定位。围绕当前竞争解释选择能区分原因的少量对照；独立实验、批次与重复进样分开。文献检索负责真实先例和 SI 条件，写作仅整理已有证据。

## 何时交计算或单晶
构象影响接近面、NOE、J 或位移时，交计算做结构一致的候选比较；反应选择性需要竞争 TS 与一致能量/溶剂/温度口径，不拿单个轨道图或基态能差代替动力学结论。单晶给出当前模型的连接/构型证据，需要核对样品、原子映射、数据质量和绝对结构限制。接回结果后回答原有机问题，避免不断重开整套流程。
