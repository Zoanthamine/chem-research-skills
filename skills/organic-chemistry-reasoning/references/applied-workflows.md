# 结构基础工具与有机推断的联动

## 图片、结构文件与可计算结构
优先识别、绘制编辑、格式转换和结构身份核对，随后才按问题调用更昂贵的软件。scripts/structure_cli.py 提供本地 info、draw、convert、ocsr、doctor、selftest；scripts/workbench.py 提供依赖配置和完整模块搜索。用 --help 读取实际参数，不需要把工具注册成另一批技能。

图片识别先裁出单一分子，保留原图和哈希；MolVec/其他 OCSR 输出是候选。将候选重新绘图，对照元素、键级、环、缩写、电荷、楔线与原子编号。结构编辑可用已有 Ketcher 或 codex-chem 的审阅入口，用户修改后的结构作为后续真源。普通知识讨论不强制打开编辑器；真实结构不明时不能用名称猜一个结构继续数值工作。

## 机理与反应成败
围绕当前键变化组织竞争解释：起始物、试剂、酸碱状态、溶剂温度、顺序、水氧与保护基兼容性。把反应转化、分解、取样、淬灭、萃取和分离损失分别放回实际阶段；TLC 转化、LCMS 响应和分离产率不能互相替代。

需要机理图时使用 modules/organic-chemistry-assistant 的完整 MechanismSpec、电子箭头、状态、原子映射和示例，而非只画好看的反应式。每一步检查电荷/原子守恒、成断键和并发箭头。程序检查通过仅说明其支持的记账条件，不证明动力学、选择性或真实机理；图、spec 与 trace 应来自同一导出。

## 三维、对照与文献
距离、二面角、构象来源和坐标映射先核对，位阻问题再按需使用专门描述符；不要由单一静态结构宣布进攻面。DOE/实验设计模块用于选择能区分竞争解释的对照，显式区分独立重复、批次与交互因素。分析方法验证与不确定性模块在需要定量/迁移方法时加载。

由波谱提供实测身份证据，单晶提供当前模型连接/构型证据，计算提供条件匹配的预测，学术研究查相似底物的原文先例；写作复用这条证据链。复杂路线拆解才衔接逆合成辅助。所有完整专门方法见 CAPABILITIES.md。
