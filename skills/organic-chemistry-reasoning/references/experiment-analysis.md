# 有机实验成败复盘与优化

## 定义成功标准

先区分：底物是否消耗、目标物是否形成、选择性是否达标、是否分离到足量/足够纯样品、是否复现。TLC点消失不等于目标产物形成，LC-MS出现目标m/z不等于结构正确或高产率。

按实际数据区分转化率、目标物测定产率、分离产率、化学/区域/立体选择性和纯度。说明计量基准、限量试剂、测定方式与校准。常见简单计量条件下产率与转化率×选择性可联系，但需先统一物质的量基准、化学计量和定义。TLC、不同化合物的未经校正UV/MS峰面积不能直接当物质的量比例。

## 沿物料去向定位问题

| 观察 | 优先考虑的分支 | 最有用的区分证据 |
|---|---|---|
| 底物多、目标少 | 活性不足、传质、试剂/催化剂失活或条件不匹配 | 取样时间轨迹、有效对照、实际条件与文献差异 |
| 底物少、目标少 | 竞争反应、分解或检测遗漏 | 粗产物谱、主要副产物、物料平衡与取样回收 |
| 目标先升后降 | 进一步反应、逆反应或产物不稳定 | 时间轨迹、产物在反应条件中的稳定性对照 |
| 粗产物好、分离产率低 | 淬灭/萃取/吸附/分馏损失或分离中分解 | 反应液、各相/馏分及后处理前后分析 |
| 产物质量异常偏高 | 溶剂、水、盐、混合物、错误分子量/计量 | 干燥状态、核磁、质量与组成核对 |
| 同条件结果漂移 | 批次、水氧、设备、温度/搅拌、加料历史或分析波动 | 独立复做、完整记录和批次分组比较 |

先排样品标签、稀释、校准、积分、仪器/取样伪差，再归因化学。物料不闭合时明确未追踪部分；沉淀、挥发和不响应组分可能无法被单一技术看到。不要因没有观察到就宣称不存在。

## 比较文献与实际操作

核对底物/保护基/盐型，试剂形态与有效含量、浓度、当量、温度历史、气氛、水分、溶剂、顺序、时间、尺度及后处理。外观颜色只作为线索；事后想象的偏差不能当已记录事实。放大问题额外看混合、传热、加料和气液接触，不能把小试比例直接当充分条件。

## 优化围绕可检验假说

每轮写“当前观察—候选原因—改变什么—支持/反驳各原因的结果”。先用少量有效对照定位反应阶段与后处理阶段；在目标不明或结构未确认时不盲目堆条件。

独立反应复做与同一溶液重复进样分开记录。多因素优化注意交互效应；分批、换日、试剂批号和分析顺序可影响比较，必要时分组/随机化。没有误差估计时，小幅单次产率差不称显著改善。DOE仅在目标、因素范围和可靠分析方法已明确时考虑，不默认给每次讨论生成统计设计。

目标也可包含选择性、可分离性、底物兼容、重现性和成本。文献底物范围缺少某类不等于该类失败；负结果注明具体结构、条件与检测能力，不扩大为反应原理不成立。

## 结果复盘格式

给出：已确认结果；失败发生在哪一阶段及证据；按支持程度排序的原因；当前不能区分的解释；下一轮最少的区分性对照及预期。未提供的操作条件保持未知。把初步解释、经过复验的经验和可推广结论分开保存，失败实验也保留可复用的边界信息。
