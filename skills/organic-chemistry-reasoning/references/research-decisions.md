# 有机化学科研分析框架

## 以研究问题选择手段

| 研究问题 | 优先整合的证据 |
|---|---|
| 得到的是什么 | 分子式/HRMS、NMR连接、必要时晶体与标准品 |
| 为什么在这里反应 | 实际活性物种、电子分布、酸碱/配位、局部位阻及竞争位点 |
| 为什么得到这个异构体 | 构象、进攻路径、立体电子要求、可逆性与立体分析 |
| 为什么反应不好 | 时间轨迹、物料平衡、粗产物与分离后比较、有效对照 |
| 机理是否成立 | 守恒、文献、排他性实验、动力学与必要计算 |
| 怎样形成研究方向 | 可重复现象、竞争解释、关键未知量及最有区分力的实验 |

## 反应位点与选择性

列出真实存在的竞争亲核/亲电、酸碱与配位位点，区分中性结构和条件下的活性物种。共振、诱导、共轭、极化、软硬匹配和局部位阻一起解释；静态电荷、Fukui指标或某个pKa值均不是通用反应排序器。

把化学选择性、区域选择性、非对映/对映选择性及构象选择分开。检查可接近性和所需轨道排列，再判断是否适合用Felkin–Anh、螯合控制、环构象或其他模型。先列适用前提和相反预测，不按反应名直接贴模型。

对映面Re/Si、R/S、E/Z等需要明确原子优先级和具体观察方向。坐标对齐和画图旋转不能改变真实构型。保留原子映射追踪新成键与立体中心，区分位置迁移、原子重排和单纯重新编号。

## 动力学、热力学和构象

产物稳定性不等于生成速率；产物比例也不自动等于平衡分布。先看反应是否可逆、何时取样、是否后续转化和差异分离。只有模型前提满足时才把产物比换成自由能差。

快速互变的反应物构象可能通过不同反应势垒影响比例；不能只根据基态主构象预测主要产物。讨论Curtin–Hammett等关系时核对互变相对反应的速率前提。计算比较需要同一化学计量与参考态，双分子路径还需考虑浓度/标准态。

## 从异常现象形成研究假说

先确认异常是否可复现、结构是否可靠和分析是否有偏差，再提出解释。每个假说说明可观察预测及会推翻它的证据；与最接近文献比较，找出底物、条件或证据上的具体差异。“尚未找到”不能直接等于新颖性。

讨论底物范围时围绕机制相关维度：电子、空间、官能团、配位/质子化、环与构象、稳定性。用匹配底物对检验单个解释，避免把电子和位阻同时变化后的结果全归于其中之一。保留失败底物和检测边界。

## 推理的停止条件

当多个候选都能解释当前数据时，给出并列候选和最有区分力的补测，而不是继续修饰故事。高成本计算应回答一个可改变决定的具体问题。研究结论围绕可复现事实及证据强度形成，漂亮结构图、单个谱峰或最低能结构都不单独充当最终证明。
