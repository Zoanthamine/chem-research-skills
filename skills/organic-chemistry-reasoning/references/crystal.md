# 单晶判读与处理决策

## 根据输入决定能做什么

| 输入 | 可支持的工作 |
|---|---|
| 只有结构图片或报告 | 解释展示结果，列出需核对的原始字段 |
| CIF/RES，没有配套强度 | 文件、组成、连接、几何和模型诊断；不能声称重新完成实验精修 |
| 配套INS/RES/HKL | 可建立精修对照；实际运行需要精修程序 |
| 积分强度及实验信息 | 可调查标度/吸收问题；不等于可以重积分 |
| 完整原始衍射帧及仪器几何 | 可考虑重索引、积分和标度；需对应后端 |

确认文件来自同一数据/模型版本。校准、掩膜或背景帧不算完整衍射数据；不能只凭扩展名判断。没有原始帧时明确积分与几何的不可核实范围。

## 判读顺序

1. 核对晶胞、空间群、波长、温度、分辨率、完整度、重复度和数据来源。组成检查包括Z、对称多重性、占有率、溶剂/离子和电荷平衡，不能只数不对称单元中的原子。
2. 先比较元素、连接、键长/角、配位环境，再看ADP、残余密度、无序、H和占有率。与质谱不一致时先检查样品、盐/溶剂、晶体组成与离子身份。
3. 同时看R1(gt/all)、wR2、GooF、Rint/Rsigma、强反射数、参数/限制数、末循环shift/s.u.、残峰和适用的绝对结构指标。不把某个指标达标当整体正确。
4. 空间群综合消光、对称、化学和模型表现选择。较低R值、已知群索引成功或消除checkCIF警报都不能单独证明空间群。
5. 连接、相对构型与绝对构型分别作结论。绝对构型需评估异常散射、Friedel数据、指标不确定度及孪晶/模型；不能把合成预期或一个Flack数值单独当确证。

## 历史实践中保留的规则

- 多候选混用：指定当前候选、父版本和采用理由；文件名final不决定权威性。
- 弱/负强度：保留基线，排除需当前图像、仪器或独立等价观测支持。反射集合或σ改变后的R1(gt)不能直接排名。
- 无序：差密度、化学连接、互斥组分、PART与占有率/多重性一起看；先用可解释的最简单模型，限制/约束写明理由。
- 活泼H与质子转移：结合差图、价态、氢键和邻居；异常H不能靠自由精修或一句氢键解释消除。
- 弥散溶剂：残峰小或Dcalc自洽不足以排除；结合空腔、电子数、差图和结晶条件。掩膜不能掩盖错误原子模型。
- 孪晶：先确认类型与强度文件协议，再测试有依据的孪晶律。不要凭拟合改善自动解释成孪晶。
- 还原、模型与报告问题分开处理：CIF改字段不能代替重新还原。晶胞、坐标、空间群、hkl变换必须同步。
- 每项试验记录“证据—假设—同一父版本—唯一改动—结果—采用理由”；组合改动需要实际对照。

## 验证与交付

只有实际完成后才报告运行成功。最终CIF、FCF和模型须来自同一轮；改坐标、筛选或权重后重新生成配套文件。checkCIF报告绑定提交版本和模式，CIF-only不等于检查了结构因子；没有A警报也不证明绝对构型或发表适用性。

缺失实验字段保持未知，不能按旧样品补写。保留原始数据和失败分支，不为降低R或消警报编造组成、透射率、软件或实验条件。向外部服务上传数据前沿用当前有效授权；仅整理方法不意味着上传研究数据。
