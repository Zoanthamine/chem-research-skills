# 实践教训：自由基重排、构象与核磁耦合

来源：一次真实的重排产物鉴定项目（2026-10 至 2026-11）的输入、日志、结果与纠正记录，**已脱敏**：项目代号、样品编号、原子编号、未发表位移/J 值、服务器与本地路径均已替换或删除。留下的是可迁移的判断规则；新体系必须重新核验结构、计算级别和适用范围，不能把这套设置当默认。

## 资源与任务边界

- 默认最多对前 6 个构象做 DFT。细聚类不等于增加 DFT 数量；未经授权不取消上限。搜索阶段可以保留完整低成本构象库。
- 用户说“直接用之前流程”时，先查现有流程、模板、配置和提交记录，不另造高成本方案。
- 本地与集群分开管理：取消本地任务不等于取消集群任务；取消某个 TS 方案不等于取消端点自由基任务。替代任务用独立目录、独立任务号，旧结果保留。
- 取消自动监测只删除自动化，不取消量化任务；停止后记录最后检查时间，不把旧状态当当前状态，不自动恢复监测或计算。

## 结构与构象身份

- PDB 不能可靠表达全部键级、自由基和立体化学。以核验过的 MOL/SDF 图为基础，记录元素顺序、键、手性中心、氢、净电荷与多重度。
- 中性自由基示例为 0 2，xTB 用 `charge=0, uhf=1`；核磁淬灭产物是闭壳层。OH→H、CH₂OH→CH₂·、自由基淬灭加 H 不是同一操作。
- 稳定原子映射先于反应插值、TS 初猜、CH₂ 归属和表格合并；原子号从 1 开始，不同分子的同号原子不能默认同位置。
- 气相 GFN2-xTB 电子能最低、DFT Gibbs 最低、独立自由基最低是三个不同结论；由最低闭壳层衍生的自由基不等于穷尽了自由基构象搜索。
- 去重后固定原始构象 ID，不按能量名次重新编号；去重不是遗漏初始构象。
- “采样到 N 个构象”只描述已采样集合，不能据此声明全局最低。几何短接触可能诱发错误力场键连，修复后必须重新核验精确图与手性。

## 核磁：屏蔽、位移与校准

| 分支 | 方法与介质 | 换算 |
|---|---|---|
| 本地快速核磁 | 气相 B3LYP/6-31G(d) 优化（无频率）+ GIAO B3LYP/6-31G(d)，SMD chloroform | 线性标度：δ = (截距 − σ)/斜率；仅复用同方法/基组/介质/约定的校准 |
| 集群分支 A | B3LYP/6-31G(d)，IEFPCM chloroform | 用该方法的 TMS 参考：δ = σ_TMS − σ（这是参照换算，不是回归标度） |
| 集群分支 B | mPW1PW91/6-311+G(d,p)，IEFPCM chloroform | 用分支 B 自己的 TMS 参考 |
| 集群分支 C | wB97XD/6-31G(d)，IEFPCM chloroform | 未配置匹配校准就只保留 σ，不把 σ 当 δ，不借用其他分支的标度 |

- 即使实验是 CDCl₃/298.15 K，也要说明：构象权重来自气相自由能，耦合拟合也在气相；没有计算溶剂对 J 的效应。不要从文件名或口述同音词推定溶剂。
- 标度常数只对匹配的方法/基组/输入有效；换基组、换 IOp、换溶剂都要重新确认，不能跨分支借用。

## 耦合：两套方法严格分开

以下均为 **FC-only 经验预测**，不是完整 Ramsey 四项：

| 项目 | Bally–Rablen | DU4 |
|---|---|---|
| 参考 | J. Org. Chem. 2011, DOI 10.1021/jo200513q | Kutateladze/Mukhina 2014, DOI 10.1021/jo501781b（作者 SI S2–S4） |
| 几何 | 气相 B3LYP/6-31G(d) | 气相 B3LYP/6-31G(d) |
| 性质 | B3LYP/Gen，6D，FCOnly ReadAtoms，`Int=NoBasisTransform` | 定制基组 + FC 设置 |
| 基组 | C/O 6-31G(d,p)，仅 H 为 8s1p（四个解收缩 6-31G s + 四个紧 s + p=1.1） | 逐元素：C 4-31G；N/O/F/Li/Be/B 6-31G；Si/S/P/Cl/As/Se/Br/I 3-21G*；H 8s1p |
| 标度 | J = 0.9155 × FC，无截距 | 按 CH₂ 环境，见下 |

- 0.9155 只对应“仅氢 u+1s”这一套输入，不能换成全原子/IOp 方案的 0.9117；基组原文从核验过的 GJF/GBS 复制，不凭简称重建。
- 发表方案的 Bally 输入标志是 `H F H D N`：默认 SCF 收敛与网格、`ReadAtoms/H`、`integral=nobasistransform`。不要为“保险”加 `SCF=XQC`、`NoSymm`、`scf=conver=10`、`grid=ultrafine`；SI 报这些对结果影响 0.00 Hz 却增加耗时。
- 基组资产本身有版本：u+1s 氢基组是 8 个 s 原函数 + 1 个 p（四个解收缩 6-31G s：18.7311/2.8254/0.6401/0.1613；四个紧 s：56.1934/168.580/505.741/1517.222；p=1.1）。曾用过截断的 5s1p 资产，两种结果不可比；旧运行的基函数计数只是那次运行的验收值，不能当新基组期望值，也不能把新旧 J 混进同一张表。
- DU4 同碳 ²J_HH：保留符号，单位 Hz。

| 环境 | 公式 |
|---|---|
| 普通 sp³ CH₂ | 1.240 × FC + 0.57 |
| 邻接 Cπ 的 sp³ CH₂（CH₂–C(=O)、CH₂–C=C、苄位） | 1.072 × FC − 1.66 |
| 小环 SR | 1.249 × FC + 1.05 |
| sp² CH₂ | 1.337 × FC + 0.52 |

- CH₂–O 不能因为氧与羰基共振就误判为 CH₂–C(=O)；曾把一个普通 sp³ 误标后纠正。
- DU4 的 CH₂ 环境分类是化学判断，不应由流程静默选定：先算 FC，导出逐构象原值和一个“四套公式各得多少”的工作表，再由后处理步选定并记录类别、J 与一句理由。补充误判：“小环”只指三元/四元环（五元环仍归普通 sp³）；缩醛型 O–CH₂–O 没有专用档。
- 邻接两个 π 中心的 CH₂ 保留“外推”标记，不承诺亚 Hz 精度。
- 每套方法各自做 ΣwᵢJᵢ：先逐构象标度，再带符号加权；不取绝对值、不把 Bally 与 DU4 平均，最终两张表分开交付。
- 单构象与多构象结果在文件名、表头、交付说明中分清；覆盖率只指“已计算集合”，不是全局构象覆盖证明。

## 过渡态与能垒

- 推荐流程：先摆初猜 → 本地受约束 GFN2-xTB 预优化 → Gaussian Berny TS 优化。不把无约束优化称为“xTB 找到 TS”，也不称 QST1。
- 常见可用设置示例：`UB3LYP/def2SVP Opt=(CalcFC,TS,NoEigen) Freq`，气相，多重度与电荷按体系。不要擅自加 Tight/MaxStep/UltraFine/XQC；历史方法（如 M06-2X/def2-TZVP + 溶剂）不能连溶剂、电荷一起照搬。
- `NoEigen` 只是搜索设置，不取消后验验收：正常结束 + 一个相关虚频 + 正确模态 + 双向 IRC 连接正确端点；自旋与波函数稳定性也要查。
- 只有端点/TS 的计算级别、热校正、标准态一致，才能报告能垒；旧方法的热校正不能混入新 TS。
- 未验证 TS 时，虚线只是比较引导线，不能画成“计算出的势垒”。

## 软件与排错

1. **优化完成判定**：Gaussian 可能输出 “Optimization completed on the basis of negligible forces.”；只匹配 “Optimization completed.” 会漏判。结合正常结束、驻点判定与最终 force 指标。
2. **ReadAtoms 基组尾部**：应为 `****` 后空行再 `atoms=H` 再空行；漏空行曾导致耦合计算失败。提交前检查实际写出的字节，而不是只看模板。
3. **换行与哈希**：Windows 写盘可能把 LF 变 CRLF；文本逻辑用规范化比较，归档完整性用实际字节 SHA256，两者不能混。
4. **中文路径**：RDKit 某些文件 API 直接读中文路径会失败；改用 `Path.read_text` + `MolFromMolBlock`，或传文件对象；输出用 `MolToMolBlock` 再写文件。
5. **结果来源**：文件名可能骗人（缓存文件里其实是另一构型）。核对内部 label、项目路径、元素顺序、方法、能量/校正求和与日志哈希。
6. **PBS 故障**：SSH 通不等于 qstat/qsub 服务通；qstat 超时不等于已有任务失败。
7. **提交超时**：qsub 超时表示“是否受理未知”。先 qselect/qstat 按唯一任务名对账，队列不可查时不盲目重投；成功必须保存真实任务号。
8. **远端变量**：PowerShell 会展开远端命令里的 `$变量`；优先参数化 Python/shlex 与结构化结果，防止本地提前替换。
9. **远端锁**：共享目录可能不支持 flock；用原子 mkdir 保护一次提交并留请求记录，遗留保护目录核实后再处理。
10. **日志长间隔**：CPHF/Hessian 导数可长时间无输出；不能凭几分钟无日志判挂起，更不能自动取消。
11. **FC 矩阵对角线**：Gaussian 耦合表对角线是磁旋比项（约 1e11 量级），不是耦合。解析时保留自配对会把 N(N−1)/2 对算成 N(N+1)/2 对，得到荒谬的“耦合值”；先删自配对，再用 N(N−1)/2 核对对数。

## 交付与复用

- 随表交付：校准前提、原始日志、原子映射、构象 ID、权重、覆盖范围、方法/基组、溶剂、原始与标度值。“程序正常结束”不足以证明化学正确。
- 复用项目脚本前先参数化并重审；项目专用脚本不是通用管线。
- 本页不承担任何项目的持续监测状态。
