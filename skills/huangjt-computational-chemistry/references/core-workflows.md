# 本地构象搜索到核磁计算

## 起点与采样
结构文件先核对连接、立体化学、显式氢、原子顺序、电荷与自旋。local_sampling.py 可准备或显式执行 xTB GFN-FF MD，或者用当前分子的 GRO/TOP/MDP 执行 GROMACS grompp、mdrun、轨迹导出。每个任务使用新目录，保存输入哈希和日志；不沿用其他分子的 RESP 电荷或拓扑。

GROMACS 对新分子需要重新参数化并核对力场、电荷、键/二面角、约束与温程。旧验证分子的参数只作案例，不能伪装成任意分子的自动通用后端。xTB 可作为独立采样和后续优化工具；高温轨迹只生成候选，不代表室温布居或已找到全部低能构象。

## 整理与核磁
从轨迹取帧，保持来源帧和原子映射；检查结构完整性、去重并按同一能量口径排序，选定构象后进行 DFT 优化/频率，再计算 NMR。核磁化学位移和 J 是不同性质；DFT 基组、溶剂、参照或标度必须与所选流程相配，不能把 xTB 排序直接称为精确核磁预测。

prepare_nmr_jobs.py 将选定 XYZ 构象生成逐构象 opt/freq 和 NMR 输入、方法/基组与文件哈希；默认最多 6 个 DFT 候选，数量由当前任务确认。run_gaussian_nmr.py 可复用已授权 Gaussian 执行本地任务，在频率与检查点有效后再运行 NMR，导出原始屏蔽；不会自动套通用标度系数或连接集群。

GIAO 屏蔽所用方法/基组由用户方法、校准和目标精度共同确定。现有项目的 B3LYP 与 mPW1PW91 等路径、Bally/DU4 两种 FC 拟合和精确基组文件见 nmr-coupling.md。Bally 适用的一般 HH 与 DU4 偕耦合环境分类分开，未知元素或超出范围的耦合不能强套。coupling_postprocess.py 保留签名 J、方法来源、构象 ID 和显式权重。

普通方法讨论不需要启动程序。真实本地计算先做 task-preflight；集群是可选执行位置。Gaussian/ORCA 软件与合法授权由目标机配置，分享的是完整方法与输入/运行/后处理工具。
