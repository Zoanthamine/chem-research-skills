# 方法档示例：构象、DFT、NMR 与 ECD

来源：某有机合成课题组的实际方法组合，**已脱敏**（只保留方法与参数，不含样品、结果或路径）。这是“一套自洽方法长什么样”的示例，不是推荐默认值；换体系要重新确认适用性。

## 构象与能量

| 阶段 | 方法 | 说明 |
|---|---|---|
| 采样 | GROMACS 退火（多条独立轨迹） | 记录力场、系综、温度程序、步长与帧间隔 |
| 精修 | CREST/xTB GFN1 → GFN2 | GFN1 粗筛、GFN2 收紧；两阶段阈值分开记录 |
| 去重排序 | GFN2 电子能 + 几何 RMSD | 保留父构象 ID，记录阈值 |
| DFT 优化/频率 | B3LYP-D3(BJ)/6-31G* | 只接受正常结束、收敛、零虚频的极小点 |
| 单点 | wB97M-V/def2-TZVP + def2/J + RIJCOSX | 用于自由能校正与后续加权 |
| 自由能 | Shermo（298.15 K 示例） | 明确低频处理、标准态、缩放与温度 |

## NMR 组合（三套并行，互不混用）

| 组合 | 优化/频率 | 屏蔽 | 溶剂模型 | 用途 |
|---|---|---|---|---|
| A | B3LYP/6-31G(d) | GIAO B3LYP/6-31G(d) | SMD chloroform | 常规定性对比、DP4 类比较 |
| B | mPW1PW91/6-311+G(2d,p) | 同方法 | IEFPCM chloroform | DP4+ 分支示例 |
| C | wB97XD/6-31G(d) | 同方法 | IEFPCM chloroform | STS 分支示例 |

规则：每套组合用自己的 TMS 参照或标度；没有匹配校准就只保留 σ；不同组合的位移、J、权重不能混表。

## 耦合

- Bally–Rablen 标度（FC-only，J = 0.9155 × FC）适用于普通 H–H；
- DU4 在本示例中只用于同碳 ²J_HH（按 CH₂ 环境分档）；
- 两者分别加权、分别出表；不取绝对值后再平均。

## ECD

- 方法示例：PBE1PBE/TZVP、CAM-B3LYP/6-311G*、B3LYP/6-311G*；SMD methanol；约 30 个激发态。
- 逐构象保留旋光强度与波长；加权后再与实验谱比较，记录展宽与波长移动。

## TS / IRC 示例

- TS：M06-2X/def2-TZVP，`CalcFC,TS,NoEigen` + 频率，SMD acetonitrile（历史示例，换体系需重审）。
- IRC：B3LYP/TZVP，`CalcFC,LQA,MaxPoints=200,Recalc=10`。
- 羰基体系：优化/频率 wB97X-D/def2-TZVPP；对比单点可用 wB97X-D、PBE0、HF + aug-cc-pVTZ，并做 `Stable=Opt`。

## 使用方式

1. 先确定“这次要回答什么问题”，再选最小组合；不要把所有方法串成一条长链。
2. 在输入文件或任务清单里写清方法、基组、溶剂、电荷/多重度、标准态。
3. 任何参数改动都要重新核对校准与参照；跨组合借用是最常见的错误来源。
