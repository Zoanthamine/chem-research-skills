# 后端运维：注册表、集群与程序边界

来源：一次真实本地 + 集群计算环境的配置与故障记录，**已脱敏**：主机名、IP、账号、密钥路径、集群绝对路径与本地盘符已删除，替换为占位符或类别描述。这些是“怎么组织与排错”的经验；具体路径必须由目标机自己的配置决定。

## 单一事实源

- 运行时路径、解释器、软件位置和公共环境变量集中在一份注册表（示例：`environments.json`）里维护；启动器、MCP 和旧脚本都读它，不另建平行配置。
- 先读注册表再执行；“技能已安装”不等于“后端已安装”。只查 PATH 会漏掉 GUI 安装的程序（Gaussian、CYLview、Mnova 等）。
- 环境按用途隔离：默认科研环境、逆合成环境、DIALS 专用环境分开；别名（core/chem/xrd/literature）指向同一环境，不是多套环境。
- 迁移到新机时不要复制旧机路径；用 `tools/doctor.py` 看本机有什么，再按 `docs/QUICKSTART.md` 配置开源部分。

## 程序边界

- **Open Babel**：格式转换与初始 3D；转换后必须核对键、氢、电荷、立体化学和原子顺序。
- **RESP/Sobtop**：拓扑与电荷准备；归档交互选择，校验总电荷与参数。
- **GROMACS**：多条独立退火轨迹；检查 `grompp`、末帧、LINCS、NaN 与轨迹完整性。
- **VMD**：文本模式跑 Tcl，先数帧，保持原子顺序。
- **CREST/xTB**：区分“独立采样”与“mdopt 集成精修”；记录阈值与输入集合。
- **Gaussian**：核对正常结束、收敛、虚频；不要把“无频率优化”说成已证实极小点。
- **ORCA**：用全路径调用 driver；并行度写在输入里；不要用 mpirun 启动 driver。
- **Shermo**：按构象 ID 配对频率日志与 ORCA 能量；权重必须归一。
- **Multiwfn**：设置 `Multiwfnpath`/`settings.ini`；版本升级会改菜单，脚本要回归。
- **NMR/ECD**：逐构象保留原始性质、权重、原子映射、校准、溶剂、展宽与波长偏移。

## 集群与调度（通用清单）

- 登录用站点既有认证方式；需要解锁的加密私钥在交互终端完成，不要把口令或私钥写进任何技能、脚本或可分享包。
- 调度器（PBS/Slurm）工具目录、家目录、Gaussian/ORCA/xTB 安装目录都应以占位符记录在注册表，例如 `<cluster-home>/software/gaussian/g16`。
- 提交前：确认队列名、核数、内存、walltime、模块加载顺序；提交后保存真实任务号与回执。
- 结果回收：只读流式下载 + 哈希校验；不要把“下载成功”当“数据已迁移”。

## 已踩过的坑

1. **ORCA MPI 混用**：ORCA 6.1 需要匹配的 OpenMPI 4.1.8；若模块先加载了旧版 OpenMPI，会在积分流附近整机卡死。为 ORCA 重建 `PATH`/`LD_LIBRARY_PATH`，把 `OMP_NUM_THREADS`/`OPENBLAS_NUM_THREADS`/`MKL_NUM_THREADS` 设为 1，再验证 `mpirun` 与 `ldd orca_startup_mpi`。
2. **ORCA 成功判定**：必须同时有 `FINAL SINGLE POINT ENERGY` 与 `ORCA TERMINATED NORMALLY`，且无 MPI/OOM/SCF 失败。`MaxCore` 是每进程 MB，`MaxCore × NProcs` 要留足内存余量。
3. **随机种子不可复现**：`gen_seed=-1` 的历史运行出现不可复现与 LINCS 失败；对已成功体系记录固定种子并保留回归用例。
4. **构象身份**：用带稳定 ID 的清单；去重与重排时保留父 ID；DFT 优化后重新去重。
5. **谱学可追溯**：每个构象保留原始屏蔽/旋光数据；固定 NMR 校准或 ECD 波长移动都要记录来源。历史脚本硬编码“中性单重态”或固定 top-N 的，必须逐项目复核。
6. **GFN1/GFN2 阈值**：细聚类常用 `Edis 0.2`，`Gdis` 按阶段取 0.20（GFN1）或 0.10（GFN2 及以后）；阈值是项目参数，不是通用常数。

## 交付习惯

- 程序日志、输入、回执、哈希与最终表一起归档；交付说明写清方法、基组、溶剂、温度、标准态、权重来源和未解决项。
- 只做静态检查时明确说“静态检查”，不宣称已完成软件、模型或科学结论的验收。
