# 化学文献研究

先判断任务是查一条文献、检索反应先例、精读一篇论文、引文核验，还是明确要求系统综述。按请求规模做事，普通查找不升级为全套综述或固定数量的文献收集。

## 工作流程

1. 从现有上下文提取结构、反应类型、底物、催化体系、目标主张或 DOI。缺少的信息只有影响检索方向时才追问。
2. 查指定论文先用标识符定位；找反应先例则用结构名称或同义词、成键变化和关键条件形成检索式。记录实际数据源、检索式、日期和筛选范围。
3. 用作者、题名、年份、期刊及 DOI 核对身份，区分预印本与正式版本。下载或解析全文后，明确读到正文、SI、摘要还是二手报道。
4. 对反应条件提取底物与产物、规模、当量、催化剂、溶剂、温度、时间、后处理、纯化、产率口径及原文位置。文中未报告的字段保持未报告。
5. 对机理主张分别记录实验观察、作者解释、计算支持及竞争解释；相似底物先例不自动证明当前底物适用。
6. 给出符合问题规模的结果、直接来源链接或标识、证据位置、限制及未闭合项。批量任务以 DOI 或规范身份去重，保留来源与版本关系。

## 选择已有模块

需要现有工具时读 [模块分工](references/modules.md)，只选当前环节的一个主要实现。可直接使用目标环境提供的学术连接器、文献 API 或网页工具；先核对工具是否存在及实际返回内容。在线检索失败时报告范围，不能伪造检索、全文或否定结论。用户提供完整记录的离线整理无需联网。

模块未安装时本入口仍能指导检索和证据整理；安装本技能不代表获得期刊订阅或第三方服务。全文依用户已有访问权限或开放来源取得。现有会话授权持续有效，实际外传未公开研究材料时才核对其范围。

跨任务衔接见 [协作与迁移](references/system-integration.md)。输出报告、表格或 Word 时使用目标环境已有的文档工具。
