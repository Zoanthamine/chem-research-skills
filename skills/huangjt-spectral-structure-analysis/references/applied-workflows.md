# 从数值谱图到候选判断的联动

## 先区分输入和任务
图片、峰表、处理后连续谱和原始 FID 需要不同方法。先确认样品批次、溶剂、谱种、横纵轴、单位、校准和处理版本；图像只能支持可读范围内的判读。专有格式需真实转换器，不能因后缀相同假称所有文件能读。

1. 原始 NMR：modules/nmrglue 的读取、采集参数、窗函数、傅里叶变换、相位/基线与频率轴知识配合 scripts/process_1d.py；所有参数来自实际元数据。不能凭外观自动设定定量条件。
2. 二列文本或支持的 JCAMP：modules/spectrum-analyzer 处理数值与图，scripts/evidence_cli.py 保留输入哈希、轴/峰窗/积分等证据；峰表和连续谱分开，避免把每一个数据点当峰。
3. NMR 归属：结合积分、裂分、HSQC 直接配对、COSY 片段、HMBC 距离限制及 NOE/ROE 空间证据。NOE 有符号体积、距离平均和候选几何是不同环节，先检查重叠、运动和自旋扩散影响。
4. MS：先核对电荷、加合离子、质量误差、同位素和碎片守恒。modules/matchms 与 pyopenms 分别支持 MS/MS 预处理/相似性与 LC-MS 数据流程；谱库需要另行取得，匹配分数不能单独确证结构或纯度。
5. 多候选：保留不能匹配的峰、缺失碳、重叠与副产物解释；由有机主技能核对反应来源，需要预测位移/J/构象才交计算主技能。最后明确哪些组成、连接和构型已经被何种证据支持。

IR/拉曼、UV-Vis、CD/ECD 使用各自信号定义、单位和条件；HMBC、耦合和 NOE 方法不跨谱种套用。绘图和报告只整理经过核实的数据，保留原数值和处理日志。
