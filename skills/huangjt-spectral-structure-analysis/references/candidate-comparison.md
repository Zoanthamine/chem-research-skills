# 结构与计算比较

以确切连接图和立体结构文件为准。原子编号通过元素、键图及必要立体映射核对；两个Gaussian任务的相同编号不表示同一化学位置。保留SMILES/SDF、模型身份、输入/输出和未确定立体信息。

HRMS先区分中性质量与离子m/z，记录电荷、[M+H]+/[M+NH4]+/[M+Na]+等、理论/实测/ppm、同位素与共洗脱。全运行强度加权质心不是单张峰顶质量。不同峰顶时间或弱单扫描需降低权重。加合离子强度不等于摩尔组成，EIC信号比例不是产率。脱OAc水解净减C2H2O、脱丙酮叉净减C3H4与气相中性丢失要区分。同分子式重排HRMS不能区分；证据需回NMR。

预测记录几何优化、频率、溶剂、单点能、自由能、温度、选取范围和权重。cap/topN覆盖只针对搜索到的集合。通过conformer ID配对，保留缺算；单构象占86%也不能冒充完整加权，不能只乘0.86就结束。属性任务另优化几何而沿用父权重时明确这点。

位移δ与屏蔽σ分开。同级TMS参照、固定经验标度、实验回归分别标注，方法01/02/03不可混列择优。STS系数应核查实际公式，例如p=aσ+b，不自行倒置。未标度方法系统误差不能直接拿全局RMSE算结构概率。局部碳偏差只能辅助搜索窗；不能将新目标位点校正到想要结果后当独立支持。

本例Bally=0.9155×FC，用于普通HH和邻位；DU4按化学环境用于CH2偕2JHH，保留signed FC、slope、intercept、环境与外推标志。它们不是可随意平均的两次测量，也不代表完整Ramsey四项。先每构象分别标度、再带符号加权、最后取|J|与表观实验裂分比较。环境应由真实图核验：普通sp3、邻π、小环以及双π外推；旧README分类不能盖过当前协议。不要将本例的所有系数当通用计算方法，无匹配协议时读原文并复核。
