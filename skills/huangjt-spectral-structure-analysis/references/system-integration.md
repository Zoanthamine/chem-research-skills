# 六个主技能的协作约定

四个化学核心分别保持完整，学术检索阅读和学术写作各有一个完整入口。其他同领域能力已经成为主技能内部模块，不再作为同级技能抢任务。模块按需读取，不能把一个简短问题升级成全部流程。

| 当前问题 | 主技能 | 必要时交接 |
|---|---|---|
| 这个反应做成了吗、选择性、机理、位阻与条件 | organic-chemistry-reasoning | 实测谱交波谱；先例交学术研究；需量化区分时交计算 |
| 核磁质谱、目标峰、粗谱杂质、NOE 与候选 | huangjt-spectral-structure-analysis | 计算位移或 J 交计算；反应来源交有机；单晶连接交单晶 |
| 构象、核磁计算、轨道、热力学、TS IRC | huangjt-computational-chemistry | 保留原子和构象 ID；结果交回解谱或反应问题 |
| 解单晶、精修、无序、孪晶、警报与 CCDC 包 | scxrd-refinement | 配体化学交有机；不把最低 R 或零 A 警报等同正确模型 |
| 文献发现、全文 SI、阅读理解、引文与知识库 | huangjt-academic-research | 结构问题回对应化学核心；需要表达成品交写作 |
| 写作润色、汇报、科研图表、PPT Word、审稿 | huangjt-academic-writing | 科学判断来自四核心；新证据核验来自学术研究 |

## 交接与完成

复用当前会话已经确定的样品、结构、文件和授权，不重新开题。交接只带问题、来源、原子/候选/构象 ID、真实条件、支持证据和冲突缺项。实测、预测、文献报告和用户确认分开。接收模块解决当前缺项后回到主问题，不重复用户已完成的分析。

最终回答直接给结论与证据；只有复杂判断才使用表格。汇报时保留关键证据及研究逻辑，把过程日志留在项目文件。严谨方法不等于给用户堆砌防御性文字。

## 自然语言选择

用户不必报技能名。面对图片、谱图、结构文件或当前化学上下文中的“分析一下、帮我看看、是不是、继续”，从已知任务继承主技能；单独的“分析”不触发全部化学技能。新任务换领域时切换主技能，不因先前加载过就一直沿用。纯知识讨论可以使用方法而不运行后端。

## 模块、运行时与归档

当前技能的 modules 下是已吸收的工具和专门方法，入口是 WORKFLOW.md；完整包内不再注册第二层 SKILL.md。先读当前主技能的融合方法，再按模块索引加载一个具体后端。源工作流中的跨技能名字通过当前模块索引定位；旧名字不是要求重新安装。

本机实际解释器和程序路径继续由 $CODEX_HOME/tools/science/environments.json 与 INTEGRATION.md 维护，通过 science.ps1 运行。兼容目录保留旧工具路径，仅用于运行兼容，不是活动技能入口。资料库、许可证、外部模型、账号与机器配置各自核验。

不相关领域和粉末扩展已在 Codex home/skill-archive/consolidated-20261102 归档。需要某项扩展时先读该归档的目录和能力边界，可直接参考方法；确需恢复到活动库时按目录映射还原，拒绝覆盖新内容。现有通用编程和内置文档能力继续保留。
