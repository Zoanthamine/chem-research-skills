# 多肽谱峰与肽迹交接

本核心处理原始谱、峰表、RT、强度、误差、谱种和仪器口径；有序列和反应上下文时可衔接已安装的 `peptide-side-product-diagnosis`（肽迹/PepTrace）。它是独立可选扩展，六入口安装器仍只安装原六个主技能。

传递：原始序列、N/C端、保护/修饰位点、二硫或其他连接、实际处理步骤及明确否定的条件；观测是中性质量、m/z、质量差还是双峰；电荷、加合、质量口径、实测容差与数据来源均保留。未知信息不补猜。

肽迹的候选、冲突、来源线索和支持路径是不同类别。质量吻合不等于位置/结构确证；MS1同式候选用实际MS/MS、对照、标品或其他证据区分。TIC/XIC面积与纯度/浓度需校准及明确测量口径，不从处理模块自动推得。

未安装时可查看 [PepTrace仓库](https://github.com/Zoanthamine/PepTrace) 和 [v1.1.0版本](https://github.com/Zoanthamine/PepTrace/releases/tag/v1.1.0)。该版本还有SPPS注意项、HPLC检查、MS1迹线、环图和规程基础模块；只按当前任务调用相关功能，不自动引入重型模型或外部服务。
