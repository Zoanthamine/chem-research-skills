# 案例复盘：Barton 脱氧产物的重排鉴定（已脱敏）

来源：一次真实的谱图解析与结构鉴定项目，**已脱敏**：样品编号、分子式、精确质量、位移/J 数值、构象权重与文件路径均已删除或泛化。保留的是“证据怎么组织、哪里容易错、什么不能宣称”。

## 问题形态

目标是把一个“直接脱氧”的预期产物与实验谱对上；实际谱图提示体系经历了重排。候选链并非一次到位，而是：

```text
预期直接脱氧产物
  → 杂质/甲基排查
  → 多出来的 CH₂ 归属
  → 新环丙烷候选
  → 芳基迁移（七元环）候选
  → 七元环开环烯烃重排候选（最终被用户确认）
```

每一步都要求给出**具体结构图**，不能只用“重排 N”这种名字当结构定义。

## 证据怎么组织

| 证据 | 作用 | 边界 |
|---|---|---|
| HRMS（[M+NH₄]⁺、[M+Na]⁺） | 确认分子式/加合离子 | 不区分同分子式异构体；ppm 误差要写清理论值 |
| ¹H/¹³C + HSQC/HMBC | 连接与计数，找多出的 CH₂、季碳 | 重叠区与弱峰不能强行唯一归属 |
| 耦合常数（含同碳 ²J） | 区分 CH₂ 环境（普通 sp³ / 邻 π / 小环 / sp²） | FC-only 预测有系统偏差，只作支持 |
| DFT 计算的位移/J | 候选结构对照 | 先核对方法/基组/参照是否与实验条件匹配 |
| NOE（体积比、混合时间） | 空间接近性 | 不作精确测距；单一模型未必能同时重现所有体积 |
| 化学推导（机理） | 提出候选与竞争路径 | 不能替代谱学证据 |

## 这次真正踩到的坑

1. **样品标签可能反了**：先按文件编号推断，发现两瓶信号与底物编号相反；改标签前先用谱学交叉验证，不能只信文件名。
2. **弱 CH₂ 信号**：某个亚甲基在碳谱几乎看不到，氢谱也弱且与羰基 α 位重叠；一度被误当作新环丙烷的特征，最后按重排结构解释。弱峰不要因“符合预期”就采信。
3. **季碳缺失**：若干季碳（含桥头/烯季碳）未找到可靠独立峰，重叠区无法唯一对应；交付时保留逐信号不确定性，不补全。
4. **同碳 ²J 的模型选择**：不同候选结构给出的 ²J 预测差异明显，可作为区分证据；但要按 CH₂ 环境选 DU4 档位，且只与实验同碳耦合比较。
5. **NOE 体积比**：实验体积比与两套构象模型的 r⁻⁶ 有效距离不能同时被任一模型重现；因此 NOE 只写成“支持/不支持”，不写成“确证”。
6. **计算与实验条件不一致**：构象权重来自气相自由能，J 也在气相计算；即使实验是 CDCl₃，也不能声称已计算溶剂效应。
7. **峰表与归属分离**：碳/氢标签并不都是精细拟合中心；把“标签”当“精确归属”会过度解读。

## 可复用的交付规则

- 每个候选结构配一张明确结构图 + 关键证据表（支持/反证/未知）。
- 最终结论写“在现有证据下最可能”，并列出未解决信号与可补证的实验（如补充二维、变温、衍生化、单晶）。
- 预测值、实验值、标度后值分列；方法、基组、溶剂、参照、权重来源随表交付。
- 原始数据、处理矩阵与脚本哈希保留；归档不等于数据已迁移。
- 用户确认结构后，仍保留逐信号不确定性；后续补证可更新，不覆盖历史。
