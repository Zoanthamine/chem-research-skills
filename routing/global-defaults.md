# 化学科研默认入口

化学及相关学术任务优先使用以下六个主技能。四个化学核心是本用户跨项目的默认方法，按问题选择一个主入口；不要求用户点名，不同时预加载全部正文。

| 任务或简短说法 | 默认技能 |
|---|---|
| 单晶、修单晶、晶体结构、无序孪晶、警报、CIF/FCF | scxrd-refinement |
| 计算、核磁计算、构象退火、轨道、Gaussian/ORCA、TS/IRC、化学作业 | huangjt-computational-chemistry |
| 解谱、看谱、目标峰在哪、原料副产物、核磁质谱、多谱归属 | huangjt-spectral-structure-analysis |
| 有机、结构式识别、画结构、SMILES转换、机理、位阻、选择性、反应成败、淬灭分离 | organic-chemistry-reasoning |
| 找文献、SOP/procedure、SI、读论文、DOI、引文与Zotero | huangjt-academic-research |
| 写作、润色、日报汇报、科研图表、论文PPT/Word、审稿回复 | huangjt-academic-writing |

技能目录为 `{{SKILL_ROOT}}`。从对应目录读取 SKILL.md；即使目录未完整出现在当前简略清单中，也可通过明确路径读取。使用宿主现有的技能加载或文件读取工具，不假设某个平台专属API存在。

“看看这个、分析一下、继续、是不是”按当前附件和化学问题继承主入口；有机语境里的“计算”才指向计算化学。需要另一类证据时按统一交接规则调用相应核心，保持样品、原子/构象ID、条件和有效授权。专业模块从主技能的 modules 索引按需读取 WORKFLOW.md，避免重新启用旧平级入口。

纯知识讨论直接使用方法；缺少后端只限制实际运行，不妨碍有依据的推理。安装、计算提交、网络访问与外传数据仍遵循当前任务权限；此默认规则不自动启动程序、安装依赖或重启已停止任务。一般编程、电脑维护和图片等非化学任务继续使用对应通用技能。
