# v1.3.3：六入口本地更新同步

以当前公开v1.3.2为基线，逐项比较本机六个主技能，保留远端已有改进。同步可移植更新，继续安装六个完整入口、47个默认模块，写作仍为7个默认模块；32个可选方法保留原去向。

更新：六入口的跨宿主能力映射；四核心的可配置经验层；解谱交接到当前有机/计算核心并按需使用独立肽迹；CREST短输入名、实际路径字节与线程接口检查；FCF诊断副本的真实权重/波长来源核对。

已有正确的Bally 8s1p、DU4基组哈希、FC对角线排除与方法校准边界不回退到本地旧说明。真实样品、站点与程序路径、个人校准、历史回执和未标许可的上游原件保持已有公开边界与获取方式，未直接复制进本版。

本版为入口/方法/索引同步，未重跑量化任务或实际晶体精修；安装完整性、目录一致性、原有离线测试和跨平台CI据实际结果记录。升级可先 `python install.py --check`，再按目标宿主运行安装器；已有不同内容需先比较，明确替换时 `--replace` 会备份。
