# 给新电脑助手的首次配置流程

目标是配置本机可持续使用的化学科研工作台，并学会六个技能的结构、选择与协作；不要求重建作者电脑，也不要求一次安装全部外部程序。

## 1 读取与检查

先读README、THIRD_PARTY和六个SKILL.md的入口，再按当前任务读取参考；不要一次加载78个方向。保留四个化学核心各自完整，两个学术技能负责证据和成品。

只检查与安装有关的操作系统、架构、可用资源、现有Python和当前宿主，确认Codex或DSH实际数据目录。优先复用已验证软件和环境，不读取账号密钥或大量无关文件；把需要用户登录、付费授权或系统权限的步骤单独列出。

## 2 先装技能和默认规则

从本仓库下载或克隆源码，在干净目录运行python install.py --check，然后为当前使用的宿主安装；若两者都已使用，可选择both。自定义数据目录依README的参数指定，不假设作者的盘符存在。

默认规则将四个核心前置为化学任务入口，两个学术技能按需衔接。已有同名不同内容时先比较并备份；只有用户任务确实授权替换时才使用--replace。不要覆盖其他项目规则，不再把内部WORKFLOW注册成大量平级技能。

## 3 自主选择最小软件集合

结合用户的日常任务和本机条件，先建立能够支持当前任务的最小环境。用户未提供具体任务时，先完成技能和常用数据处理基础，汇报可直接使用的能力；不要为了显得完整下载所有量化程序、模型和数据库。

结构与质量、核磁或质谱数据、单晶CIF与强度、文献阅读和Office成品分别依据相应核心的实际脚本和宿主工具选择依赖。优先已有可用后端，缺少的免费或开源依赖在任务授权范围内自行配置；安装前核对当前官方来源、平台支持和许可，不执行来历不明的一键脚本。

常规Python处理、DIALS、逆合成或其他有依赖冲突的后端分环境；不要为适配一个可选模块破坏现有工作环境。大型程序、GPU专项构建、模型或集群接入按当前需求选择，程序存在、版本可运行、许可证可用和当前方法验证是不同状态。

安装位置按用户指定的数据盘和系统习惯选择；程序、环境、模型与用户研究输出分开，不硬编码作者的E盘或D盘。外部账号、密钥、付费授权和需要人工操作的权限步骤再向用户说明，其他可逆常规操作继续自主完成。

## 4 验证并给出使用方式

核对六个入口可发现或可从全局路径读取、默认规则只添加一次、内部模块没有额外SKILL入口。运行安装器校验和与当前后端有关的小型示例；能运行本仓库波谱doctor/selftest时据实执行，单晶合成测试不当成真实样品精修。

实际任务中沿用样品、原子与构象ID、条件和来源，避免一个问题开多套流程。只做了静态检查就明确是静态检查，不能宣称已完整验收软件、模型或科学结论。

最后简短报告已安装的技能和环境、可直接使用的能力、需要用户处理的授权，以及如何更新和恢复备份，并给出“修单晶、核磁计算、解谱、有机、找文献、写作”六种自然语言用法。用户不必记英文目录名。
