# 内容去向与四核心配置

v1.2.0 默认以四个化学核心为主，学术研究和写作为支持。完整目录统计主技能自身的脚本、方法和内部模块，不再把单晶来源子模块的“0 个额外脚本”当作整个核心的统计。

学术写作从 39 个模块位置收敛为 7 个：nature-writing、nature-polishing、nature-response、nature-proposal-writer、paper-write、office-academic-skill、nature-shared。其余 32 项退出默认包，原始内容保留在本地及固定 v1.1.0 版本；可选方法索引和恢复命令见写作 references/optional-methods.md。不同内容不覆盖，恢复后仅为内部模块。

四核心原有代码、参考和经验保留，新增本地采样/NMR 任务和真实谱文件读取入口。单晶来源模块增加四个随包知识章节，直接衔接主技能的完整参考与工具。仍不随包的原始来源通过既有 fetch-source 和上游链接取得，不能据此删除方法。

原 252 项技能的归属记录仍在 catalog/original-library.json；这是一份历史处理索引，不是要求全部安装。非相关领域和粉末扩展继续归档，不卸载用户软件。个人路径、样品、许可证和服务器凭据不随公开包迁移。
